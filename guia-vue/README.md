# Guia Complementar de Vue 3

Este guia consolida o treinamento de Vue 3 realizado neste workspace. Ele foi
escrito para consulta posterior por quem ja conhece TypeScript, React e Angular;
por isso, evita fundamentos de JavaScript e enfatiza diferencas de modelo mental,
armadilhas e decisoes profissionais.

## Stack de Referencia

- Vue 3 com Composition API e `<script setup>`
- TypeScript
- Vite
- Vue Router
- Pinia
- VeeValidate e Zod
- Vitest e Vue Test Utils

## Como Consultar

Cada modulo contem:

- o problema que as APIs resolvem;
- comparacoes com React e Angular;
- sintaxe essencial;
- duvidas levantadas durante o treinamento;
- armadilhas e praticas profissionais;
- links para implementacoes reais no playground `projeto-1`.

Os exemplos sao material de estudo, nao uma biblioteca pronta para producao. Ao
reutiliza-los, preserve a ideia e reavalie requisitos, acessibilidade e tratamento
de erros do contexto atual.
